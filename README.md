# TaskFlow – Smart To-Do List App

TaskFlow is a modern and user-friendly To-Do List application developed as part of my Web Development Internship at Arch Technology.

## Features
- Add new tasks
- Manage daily tasks
- Mark tasks as completed
- Organize and track your work
- Clean and responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- `index.html` – Main structure
- `style.css` – Styling and design
- `script.js` – Application functionality

## Purpose
This project was developed to improve my frontend web development skills and practical experience in JavaScript.
